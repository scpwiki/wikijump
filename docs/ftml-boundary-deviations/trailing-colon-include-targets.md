# Deviation: normalize_trailing_colon_include_targets

- Shim: `normalize_trailing_colon_include_targets` / `strip_trailing_colon_include_target` in `deepwell/src/services/render/include_resolution.rs`, applied at the head of `expand_malformed_include_targets`.
- Reason it lives in Wikijump: include source fetching, cross-site resolution, and missing-include policy are Wikijump-owned per `docs/ftml-boundary.md`. The rewrite normalizes the raw include target before the FTML include scan so lookup and the missing-include message see the Wikidot-normalized page name.
- Why FTML is not yet sufficient: FTML's `PageRef::parse` (pinned rev `17dbc23`, `src/data/page_ref.rs`) normalizes via `wikidot_normalize::normalize`, which merges all-but-last colons into dashes before stripping leading/trailing colons. A trailing colon therefore steals the last-colon slot and the real category separator is dashed (`component:license-box:` parses to page `component-license-box`, which matches no stored slug). Evidence: `wikidot-normalize-0.12.0/src/normal.rs` (`LEADING_OR_TRAILING_COLON` applied after `merge_multi_categories`) and the category-merge tests.
- Evidence: issue #2354 (Wikidot anonymous raw-HTML captures 2026-10-11: `a-semi-comprehensive-list-of-foundation-bots`, `black-moon-howl-complete-list`, `fragment:8000contestroufhous1`, `scp-7162`; page sources live = corpus `run-20260816-100230` = standing). Corpus sources: `en/pages/theme:turbo-vision/source.wikidot.txt` (line shape `[[include :scp-wiki:theme:basalt: ...]]` pattern per issue table).
- FTML backlog decision: new debt accepted Wikijump-side. The durable fix is FTML-side (strip trailing colons before the category merge in `PageRef::parse`/normalize), tracked as future BND-series work; this shim shrinks once the FTML parser handles trailing-colon targets itself.
- Migration condition: a pinned FTML revision whose `PageRef::parse(":site:category:page:")` yields page `category:page` (with the missing-include message naming the normalized page), proven by the marker-contract canary and the unit tests in `include_resolution.rs`.
